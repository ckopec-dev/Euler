# Euler Problem 358 Solution in Ada

## Problem Statement
Consider the number 142857. We can right-rotate it to get 714285, and then we can right-rotate it again to get 571428. Notice that 142857 × 2 = 285714 and 142857 × 3 = 428571. The numbers 142857, 285714, 428571, 571428, 714285, 857142 are all cyclic permutations of each other.

We call a number that is a multiple of its right-rotation a "cyclic number". Find the sum of all cyclic numbers less than 10^10.

## Solution Approach

Let me analyze this problem step by step:

1. A cyclic number has the property that when multiplied by integers from 1 to n (where n is the number of digits), it produces cyclic permutations
2. For a number to be cyclic, its decimal expansion must be periodic with period equal to the number of digits
3. The key insight is that such numbers are related to fractions 1/p where p is prime and the period of 1/p equals the number of digits
