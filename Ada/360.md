# Euler Problem 360 Solution in Ada

## Problem Statement
Find the number of lattice points (points with integer coordinates) inside the ellipse with center at origin and semi-axes a=1000, b=1000.

## Analysis
We need to count lattice points (x,y) where both x and y are integers such that:
x²/a² + y²/b² ≤ 1

With a = b = 1000, this becomes:
x²/1000² + y²/1000² ≤ 1
x² + y² ≤ 1000²

## Solution Approach
We'll iterate through possible x values from -1000 to 1000 and for each x, determine the valid range of y values. For a given x, we need:
y² ≤ 1000² - x²
|y| ≤ √(1000² - x²)
So y ranges from -floor(√(1000² - x²)) to floor(√(1000² - x²))

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Numerics.Elementary_Functions; use Ada.Numerics.Elementary_Functions;

procedure Euler_360 is
   N : constant Integer := 1000;
   Count : Integer := 0;
   
begin
   for X in -N..N loop
      -- Calculate maximum y value for this x
      declare
         Y_Max : constant Integer := Integer(Real_Part(Sqrt(Real(N*N - X*X))));
      begin
         -- Add the number of valid y values (from -Y_Max to Y_Max)
         Count := Count + 2 * Y_Max + 1;
      end;
   end loop;
   
   Put_Line("Number of lattice points: " & Integer'Image(Count));
end Euler_360;
```

## Explanation

The algorithm works as follows:

1. **Outer Loop**: Iterate through all possible x values from -N to N (where N=1000)
2. **For each x**: Calculate the maximum y value that satisfies the ellipse equation
3. **Count valid y values**: For a given x, y can range from -Y_Max to Y_Max, giving us 2*Y_Max + 1 valid points
4. **Accumulate**: Add this count to our total

## Key Points

- The ellipse equation is x² + y² ≤ N² (since a = b = N)
- For each integer x in the range [-N, N], we compute the maximum integer y such that x² + y² ≤ N²
- This gives us the number of valid lattice points for that x value
- The total count is the sum over all valid x values

## Optimization Note

The algorithm can be optimized further by noting that due to symmetry, we only need to compute for x ≥ 0 and multiply appropriately, but the current implementation is clear and efficient enough for the given problem size.

The solution correctly counts all lattice points inside or on the boundary of the ellipse.
