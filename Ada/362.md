# Euler Problem 362 Solution in Ada

Euler Problem 362 asks us to find the sum of all numbers n such that n is a palindrome in both base 10 and base 2, and n < 10^9.

Let me break this down:
- We need to check palindromes in base 10
- We also need to check palindromes in base 2 (binary)
- The range is n < 10^9
- Sum all such numbers

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_362 is
   
   type Number_Type is range 0..10**9;
   
   -- Function to check if a number is palindrome in given base
   function Is_Palindrome(Number : Number_Type; Base : Positive) return Boolean is
      Temp_Number : Number_Type := Number;
      Reversed    : Number_Type := 0;
   begin
      if Number = 0 then
         return True;
      end if;
      
      -- Convert to the given base and reverse it
      while Temp_Number > 0 loop
         Reversed := Reversed * Base + (Temp_Number mod Base);
         Temp_Number := Temp_Number / Base;
      end loop;
      
      -- Check if reversed number equals original
      return Reversed = Number;
   end Is_Palindrome;
   
   -- Function to check if a decimal number is palindrome
   function Is_Decimal_Palindrome(Number : Number_Type) return Boolean is
   begin
      return Is_Palindrome(Number, 10);
   end Is_Decimal_Palindrome;
   
   -- Function to check if a binary number is palindrome
   function Is_Binary_Palindrome(Number : Number_Type) return Boolean is
   begin
      return Is_Palindrome(Number, 2);
   end Is_Binary_Palindrome;
   
   Total_Sum : Number_Type := 0;
   Count     : Natural := 0;
   
begin
   -- Check all numbers from 1 to 10^9 - 1
   for N in 1 .. 10**9 - 1 loop
      if Is_Decimal_Palindrome(N) and then Is_Binary_Palindrome(N) then
         Total_Sum := Total_Sum + N;
         Count := Count + 1;
         Put_Line("Found palindrome: " & N'Image);
      end if;
   end loop;
   
   Put_Line("Sum of all palindromes in base 10 and 2 (less than 10^9): ");
   Put(Total_Sum, Width => 0);
   New_Line;
   Put_Line("Count: " & Count'Image);
   
end Euler_362;
```
