# Euler Problem 364 Solution in Ada

## Problem Statement
Find the number of ways to tile a 3×n rectangle with 2×1 dominoes, where each domino can be placed either horizontally or vertically.

## Solution Approach
This is a classic dynamic programming problem. I'll use the state transition approach where we consider how tiles can be placed in each column.

Let's define our states based on how the columns are filled:
- State 0: All three cells in the column are empty (no dominoes placed)
- State 1: Top cell is filled, bottom two are empty
- State 2: Middle cell is filled, top and bottom are empty  
- State 3: Bottom cell is filled, top two are empty
- State 4: Top and middle cells are filled, bottom is empty
- State 5: Middle and bottom cells are filled, top is empty
- State 6: All three cells are filled

## Explanation

The solution uses a recurrence relation approach:

1. **Base Cases**: 
   - f(0) = 1 (empty rectangle has one way - do nothing)
   - f(1) = 1 (3×1 rectangle can only be filled with three vertical dominoes)
   - f(2) = 3 (3×2 rectangle can be tiled in 3 ways)
   - f(3) = 11 (3×3 rectangle can be tiled in 11 ways)

2. **Recurrence Relation**: For n ≥ 4, 
   f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4)

3. **Matrix Exponentiation Approach**: While the recurrence approach works, for very large n values, matrix exponentiation could be used for better performance.
