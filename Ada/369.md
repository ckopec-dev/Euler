First, let me understand what Euler Problem 369 asks:
- Find the number of lattice points (points with integer coordinates) inside a circle of radius r
- The circle is centered at the origin (0,0)
- We need to count points where x² + y² < r²

Here's my Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_369 is
   type Point is record
      X, Y : Integer;
   end record;
   
   function Count_Lattice_Points(Radius : Integer) return Integer is
      Count : Integer := 0;
      R2    : Long_Long_Integer := Long_Long_Integer(Radius) * Long_Long_Integer(Radius);
   begin
      -- Check all points in the square from (-r, -r) to (r-1, r-1)
      for X in -Radius .. Radius-1 loop
         for Y in -Radius .. Radius-1 loop
            if X * X + Y * Y < R2 then
               Count := Count + 1;
            end if;
         end loop;
      end loop;
      
      return Count;
   end Count_Lattice_Points;
   
   function Count_Lattice_Points_Optimized(Radius : Integer) return Integer is
      Count : Integer := 0;
      R2    : Long_Long_Integer := Long_Long_Integer(Radius) * Long_Long_Integer(Radius);
   begin
      -- For each x coordinate, find the range of valid y values
      for X in -Radius .. Radius-1 loop
         declare
            Y_Max : Integer;
            X2    : Long_Long_Integer := Long_Long_Integer(X) * Long_Long_Integer(X);
         begin
            -- Calculate maximum y such that x² + y² < r²
            Y_Max := Integer(Sqrt(Float(R2 - X2)));

               Y_Max := Y_Max - 1;
            end if;
            
            -- Count valid y values from -Y_Max to Y_Max
            Count := Count + (2 * Y_Max + 1);
         end;
      end loop;
      
      return Count;
   end Count_Lattice_Points_Optimized;
   
   Result : Integer;
begin
```

Actually, let me reconsider this problem. The mathematical approach would be to use the Gauss circle problem. But for practical implementation, here's a more straightforward and correct solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_369 is
   function Count_Lattice_Points(Radius : Integer) return Long_Long_Integer is
      Count : Long_Long_Integer := 0;
      R2    : Long_Long_Integer := Long_Long_Integer(Radius) * Long_Long_Integer(Radius);
   begin
      for X in -Radius+1 .. Radius-1 loop
         for Y in -Radius+1 .. Radius-1 loop
            if (Long_Long_Integer(X) * Long_Long_Integer(X) + 
                Long_Long_Integer(Y) * Long_Long_Integer(Y)) < R2 then
               Count := Count + 1;
            end if;
         end loop;
      end loop;
      
      return Count;
   end Count_Lattice_Points;
   
   Result : Long_Long_Integer;
begin
   -- For the problem with radius 10^6
   Result := Count_Lattice_Points(1000000);
   
   Put("Number of lattice points inside circle: ");
   Put(Result, Width => 0);
   New_Line;
end Euler_369;
```

This solution:
1. Iterates through all integer coordinates within a square that bounds the circle
2. Checks if each point satisfies x² + y² < r² (inside the circle)
3. Counts and returns the total number of such points

The time complexity is O(r²) which works well for reasonable values of r, though for very large values like 10^6, a more mathematical approach would be needed for efficiency.
