- We have a car with 3 wheels and 30 seats
- Each passenger has a seat number from 1 to 30
- The driver chooses a random seat for the first passenger
- Each subsequent passenger takes their assigned seat if available, otherwise chooses randomly from remaining seats
- We want to find the probability that the last passenger sits in their own seat

This is actually a classic probability problem. Let me think about it:

If we have n passengers and n seats, the probability that the last passenger sits in their own seat is 1/2 for n ≥ 2.

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_371 is
begin
   -- This is a classic probability problem known as "The Secretary Problem" variant
   -- or "The Monty Hall Problem" style problem
   
   -- For n passengers and n seats:
   -- The probability that the last passenger sits in their own seat is 1/2 for n >= 2
   
   Put_Line("Euler Problem 371 Solution:");
   Put_Line("============================");
   Put_Line("Problem: 30 passengers, 30 seats. Each passenger takes their assigned seat if available,");
   Put_Line("otherwise chooses randomly from remaining seats.");
   Put_Line("");
   Put_Line("Mathematical Analysis:");
   Put_Line("----------------------");
   Put_Line("This is a classic problem with the surprising result:");
   Put_Line("- For n passengers and n seats, the probability that the last passenger");
   Put_Line("  sits in their own seat is always 1/2 when n >= 2.");
   Put_Line("");
   Put_Line("The reasoning:");
   Put_Line("- The first passenger either takes their own seat (probability 1/n) or");
   Put_Line("  the last passenger's seat (probability 1/n), or some other seat.");
   Put_Line("- If they take their own seat, everyone else sits correctly.");
   Put_Line("- If they take the last passenger's seat, the last passenger can't sit there.");
   Put_Line("- Otherwise, it reduces to a smaller version of the same problem.");
   Put_Line("- The key insight is that the process eventually leads to a 50-50 chance.");
   Put_Line("");
   Put_Line("Answer: 1/2 = 0.5");
   Put_Line("In fractional form: 1/2");
   
end Euler_371;
```

The mathematical solution is quite elegant and well-known for this type of problem. The answer is **1/2** or **0.5**.
