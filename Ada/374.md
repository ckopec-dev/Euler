# Euler Problem 374 Solution in Ada

I'll solve Euler Problem 374, which asks for the number of ways to write n as a sum of powers of 2 where each power can be used at most twice.

## Problem Analysis
We need to count the number of ways to express a number n as a sum of powers of 2 (1, 2, 4, 8, 16, ...) where each power can be used at most twice.

This is equivalent to finding the coefficient of x^n in the generating function:
(1 + x + x^2)(1 + x^2 + x^4)(1 + x^4 + x^8)...(1 + x^(2^k) + x^(2^(k+1)))

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_374 is
   
   -- Maximum value to compute (based on problem requirements)
   MAX_N : constant := 10^6;
   
   -- Memoization array for dynamic programming
   F : array(0..MAX_N) of Long_Long_Integer;
   
   -- Precomputed powers of 2
   Powers_Of_2 : array(0..30) of Long_Long_Integer;
   
   -- Function to compute the number of representations
   function Count_Representations(N : Long_Long_Integer) return Long_Long_Integer is
      Result : Long_Long_Integer := 0;
      Temp : Long_Long_Integer;
   begin
      if N = 0 then
         return 1;
      elsif N < 0 then
         return 0;
      elsif F(N) /= 0 then
         return F(N);
      end if;
      
      -- For each power of 2, we can use 0, 1, or 2 copies
      for I in reverse 0..30 loop
         exit when Powers_Of_2(I) > N;
         Temp := Count_Representations(N - Powers_Of_2(I));
         if Temp /= 0 then
            Result := Result + Temp;
         end if;
         
         -- Try using two copies of the same power
         if I > 0 and then Powers_Of_2(I-1) <= N then
            Temp := Count_Representations(N - 2 * Powers_Of_2(I));
            if Temp /= 0 then
               Result := Result + Temp;
            end if;
         end if;
      end loop;
      
      F(N) := Result;
      return Result;
   end Count_Representations;
   
   -- More efficient iterative approach
   function Efficient_Count(N : Long_Long_Integer) return Long_Long_Integer is
      DP : array(0..MAX_N) of Long_Long_Integer := (others => 0);
      Power : Long_Long_Integer;
      I : Integer;
   begin
      DP(0) := 1;
      
      -- For each power of 2, update all possible sums
      for P in 0..30 loop
         Power := Powers_Of_2(P);
         exit when Power > N;
         
         -- Update DP array from right to left to avoid double counting
         for I in reverse (Long_Long_Integer(Power)..N) loop
            if I >= Power then
               DP(I) := DP(I) + DP(I - Power);
            end if;
            
            -- Add case where we use 2 copies of this power
            if I >= 2 * Power then
               DP(I) := DP(I) + DP(I - 2 * Power);
            end if;
         end loop;
      end loop;
      
      return DP(N);
   end Efficient_Count;
   
begin
   -- Precompute powers of 2
   Powers_Of_2(0) := 1;
   for I in 1..30 loop
      Powers_Of_2(I) := Powers_Of_2(I-1) * 2;
   end loop;
   
   -- Initialize memoization array
   for I in 0..MAX_N loop
      F(I) := 0;
   end loop;
   
   -- For small values, we can use direct computation
   Put_Line("Computing representations...");
   
   -- The problem asks for a specific value, let's compute for a reasonable range
   declare
      Result : Long_Long_Integer;
   begin
      -- Compute for n = 10^6 as in typical Euler problems
      Result := Efficient_Count(1000000);
      Put("Answer: ");
      Put(Result, Width => 0);
      New_Line;
   end;
   
end Euler_374;
```

## Alternative Simpler Approach

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_374 is
   
   -- Dynamic programming approach for counting representations
   function Count_Ways(N : Integer) return Long_Long_Integer is
      DP : array(0..1000000) of Long_Long_Integer := (others => 0);
      Power : Long_Long_Integer;
      I : Integer;
   begin
      -- Base case: one way to make 0
      DP(0) := 1;
      
      -- For each power of 2 from 1 to largest needed
      Power := 1;
      while Power <= N loop
         -- Update all possible sums using this power (0, 1, or 2 copies)
         for I in Power..N loop
            -- Add ways without using this power
            DP(I) := DP(I);
            
            -- Add ways using one copy of this power
            if I >= Power then
               DP(I) := DP(I) + DP(I - Power);
            end if;
            
            -- Add ways using two copies of this power  
            if I >= 2 * Power then
               DP(I) := DP(I) + DP(I - 2 * Power);
            end if;
         end loop;
         
         Power := Power * 2;
      end loop;
      
      return DP(N);
   end Count_Ways;
   
begin
   Put_Line("Euler Problem 374 - Number of representations as sum of powers of 2");
   
   -- The answer for n = 10^6 is what we're looking for
   declare
      Answer : constant Long_Long_Integer := Count_Ways(1000000);
   begin
      Put("Answer: ");
      Put(Answer, Width => 0);
      New_Line;
   end;
   
end Euler_374;
```

## Explanation

This solution uses dynamic programming to count the number of ways to express a number as a sum of powers of 2 where each power can be used at most twice.

1. **Approach**: Dynamic Programming with memoization
2. **State**: `DP[i]` represents the number of ways to form integer `i`
3. **Transition**: For each power of 2, we consider using 0, 1, or 2 copies
4. **Time Complexity**: O(n log n) where n is the target number
5. **Space Complexity**: O(n)

The key insight is that at each step, we can either:
- Not use a particular power of 2
- Use one copy of that power  
- Use two copies of that power

This problem is related to restricted partitions and generating functions in combinatorics.
