# Project Euler Problem 375 Solution in Ada

I'll solve Project Euler Problem 375, which asks for the sum of the largest elements in each row of a specific matrix.

## Problem Understanding

The problem involves:
- Creating an n×n matrix where each element at position (i,j) is calculated as (i×j) mod 1000000
- For each row, find the maximum element
- Sum all these maximum elements

## Solution Approach

I'll create a solution that:
1. Generates the matrix elements
2. Finds the maximum in each row
3. Sums all the row maximums

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_375 is
   type Matrix_Type is array (Positive range <>, Positive range <>) of Integer;
   
   -- Function to calculate matrix element at position (i,j)
   function Matrix_Element(i, j : Positive) return Integer is
   begin
      return (i * j) mod 1000000;
   end Matrix_Element;
   
   -- Calculate sum of maximum elements in each row
   function Sum_Of_Maximums(n : Positive) return Long_Long_Integer is
      Max_Value : Integer;
      Row_Sum   : Long_Long_Integer := 0;
      Temp      : Integer;
   begin
      for i in 1 .. n loop
         Max_Value := Matrix_Element(i, 1);
         for j in 2 .. n loop
            Temp := Matrix_Element(i, j);
            if Temp > Max_Value then
               Max_Value := Temp;
            end if;
         end loop;
         Row_Sum := Row_Sum + Long_Long_Integer(Max_Value);
      end loop;
      
      return Row_Sum;
   end Sum_Of_Maximums;
```
