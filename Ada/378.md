# Euler Problem 378 Solution in Ada

I'll solve Euler Problem 378, which asks for the number of ways to write n as a sum of at least two positive integers.

## Problem Understanding

Euler Problem 378 asks us to find the number of partitions of n (the number of ways to write n as a sum of positive integers) where we consider partitions with at least two parts.

This is equivalent to finding the partition function p(n) minus 1 (since we exclude the trivial partition of n itself).

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_378 is
   
   -- Maximum number to compute partitions for
   MAX_N : constant := 100000;
   
   -- Array to store partition numbers
   P : array (0 .. MAX_N) of Long_Long_Integer;
   
   -- Function to compute the number of partitions of n
   function Partition_Number(n : Integer) return Long_Long_Integer is
      Result : Long_Long_Integer := 0;
      k : Integer;
      sign : Integer := 1;
      pent : Integer;
      j : Integer;
   begin
      if n < 0 then
         return 0;
      elsif n = 0 then
         return 1;
      else
         -- Using pentagonal number theorem for partition function
         k := 1;
         loop
            -- Pentagonal numbers: k*(3k-1)/2 and k*(3k+1)/2
            pent := k * (3 * k - 1) / 2;
            exit when pent > n;
            
            Result := Result + sign * P(n - pent);
            
            pent := k * (3 * k + 1) / 2;
            exit when pent > n;
            
            Result := Result + sign * P(n - pent);
            
            k := k + 1;
            sign := -sign;
         end loop;
      end if;
      
      return Result;
   end Partition_Number;
   
begin
   -- Initialize base case
   P(0) := 1;
   
   -- Compute partition numbers for all values up to MAX_N
   for i in 1 .. MAX_N loop
      P(i) := Partition_Number(i);
   end loop;
   
   -- The answer is the number of partitions of 100000 minus 1 (to exclude the trivial partition)
   Put("The number of ways to write 100000 as a sum of at least two positive integers is: ");
   Put(P(100000) - 1, Width => 0);
   New_Line;
   
end Euler_378;
```

## Explanation

This solution uses the pentagonal number theorem to efficiently compute partition numbers. Here's how it works:

1. **Partition Function**: The algorithm computes the partition function p(n) which counts the number of ways to write n as a sum of positive integers.

2. **Pentagonal Number Theorem**: Instead of computing all partitions recursively, we use Euler's pentagonal number theorem which provides an efficient recurrence relation:
   - p(n) = Σ(-1)^(k-1) × p(n - g_k)
   - Where g_k are generalized pentagonal numbers: k(3k±1)/2

3. **Implementation Details**:
   - We precompute all partition numbers up to 100,000
   - For each n, we use the recurrence relation with pentagonal numbers
   - The result is p(100000) - 1 since we want partitions with at least two parts

## Key Mathematical Concepts

- **Partition Function**: p(n) counts integer partitions of n
- **Pentagonal Numbers**: Generalized pentagonal numbers k(3k±1)/2 where k = 1, -1, 2, -2, ...
- **Euler's Pentagonal Number Theorem**: Provides an efficient way to compute partition numbers

## Time Complexity

The algorithm has time complexity O(n√n) which is efficient enough for n = 100,000.
