# Euler Problem 381 Solution in Ada

## Problem Statement
Let f(n) be the largest integer ≤ n that is coprime to n (i.e., gcd(n, f(n)) = 1). Let S(N) = Σ f(n) for n = 2 to N. Find S(10^8).

## Approach
This problem requires finding the sum of the largest coprime numbers for each integer from 2 to N. Key insights:
- For a number n, we want the largest k ≤ n such that gcd(n,k) = 1
- This is equivalent to finding the largest number less than or equal to n that shares no common factors with n
- We can use Euler's totient function and properties of coprime numbers

   function GCD(A, B : Long_Integer) return Long_Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
