I'll solve Project Euler Problem 385, which asks for the sum of all positive integers n ≤ 10^12 such that the function f(n) = n² + 1 is divisible by an odd prime p where p ≡ 1 (mod 4).

Let me break down the approach:

## Mathematical Analysis

For f(n) = n² + 1 to be divisible by an odd prime p where p ≡ 1 (mod 4), we need:
n² + 1 ≡ 0 (mod p)
n² ≡ -1 (mod p)

This means -1 is a quadratic residue modulo p, which happens if and only if p ≡ 1 (mod 4).

## Solution Approach

1. Generate all primes p ≡ 1 (mod 4) up to √(10^12) = 10^6
2. For each such prime p, find all n ≤ 10^12 such that n² ≡ -1 (mod p)
3. Sum all valid n values
