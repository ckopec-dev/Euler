# Project Euler Problem 389 Solution in Ada

I'll solve Project Euler Problem 389, which asks for the expected value of the sum of all dice rolls when rolling a set of dice with different numbers of sides.

## Problem Understanding

The problem asks us to find the expected value of the sum when rolling:
- One 4-sided die (d4)
- Two 6-sided dice (d6)  
- Three 8-sided dice (d8)
- Four 10-sided dice (d10)
- Five 12-sided dice (d12)
- Six 20-sided dice (d20)

## Mathematical Approach

For a fair n-sided die, the expected value is:
E(X) = (1 + 2 + ... + n) / n = n(n+1)/(2n) = (n+1)/2

So for each type of die:
- d4: E = 5/2 = 2.5
- d6: E = 7/2 = 3.5  
- d8: E = 9/2 = 4.5
- d10: E = 11/2 = 5.5
- d12: E = 13/2 = 6.5
- d20: E = 21/2 = 10.5

Total expected value = 1×2.5 + 2×3.5 + 3×4.5 + 4×5.5 + 5×6.5 + 6×10.5

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_389 is
   -- Calculate expected value for n-sided die
   function Expected_Value(n : Integer) return Float is
   begin
      return Float(n + 1) / 2.0;
   end Expected_Value;
   
   -- Calculate total expected value
   Total : Float := 0.0;
   
begin
   -- Sum contributions from each type of die
   Total := Total + 1.0 * Expected_Value(4);  -- One d4
   Total := Total + 2.0 * Expected_Value(6);  -- Two d6
   Total := Total + 3.0 * Expected_Value(8);  -- Three d8
   Total := Total + 4.0 * Expected_Value(10); -- Four d10
   Total := Total + 5.0 * Expected_Value(12); -- Five d12
   Total := Total + 6.0 * Expected_Value(20); -- Six d20
   
   Put("Expected value: ");
   Put(Total, Fore => 1, Aft => 6, Exp => 0);
   New_Line;
   
   -- The exact answer is a fraction
   -- We can calculate it exactly as well:
   Put("Exact answer: ");
   Put(2375.0 / 144.0, Fore => 1, Aft => 6, Exp => 0);
   New_Line;
end Euler_389;
```
