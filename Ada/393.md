# Euler Problem 393 Solution in Ada

I'll solve Euler Problem 393, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

## Problem Understanding

We need to count the number of ways to completely cover a 3×n rectangle using 2×1 dominoes (which can be placed either horizontally or vertically).

## Approach

This is a classic dynamic programming problem. I'll use state compression where each column can have different configurations of filled cells, and then compute transitions between states.

Let me break this down:
- Each column can be in one of several states based on which cells are filled
- We need to count valid transitions from one column to the next
- Use dynamic programming with memoization

## Mathematical Explanation

The key insight is that this problem can be solved using a recurrence relation. For tiling a 3×n rectangle with 2×1 dominoes, the sequence follows:

- f(0) = 1 (one way to tile empty space)
- f(1) = 1 (one vertical domino)
- f(2) = 3 (three ways to tile 3×2)
- f(3) = 11 (eleven ways to tile 3×3)

The recurrence relation is: **f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)**

This formula comes from analyzing the possible configurations of the last few columns and how they can be filled.
