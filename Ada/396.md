# Euler Problem 396 Solution in Ada

I'll solve Euler Problem 396, which asks for the number of ways to write n as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

We need to count the number of ways to express a positive integer n as a sum of powers of 2 (1, 2, 4, 8, 16, ...), where each power can appear at most twice in the sum.

For example:
- n = 5: 5 = 4 + 1 = 2 + 2 + 1 = 2 + 1 + 1 + 1 (but 1 appears 3 times, which violates the constraint)
- Actually, valid representations for n=5: 4+1 and 2+2+1 (2 appears twice, so this is valid)

## Solution Approach

This is a dynamic programming problem. I'll use the recurrence relation:
- Let dp[i][j] = number of ways to represent i using powers of 2 up to 2^j, with each power used at most twice
- But we can simplify: let f(n) = number of ways to represent n using powers of 2 where each power appears at most twice

We can think of this as a variant of the coin change problem with limited coins.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_396 is
   type Long_Integer is range -2**63 .. 2**63-1;
   
   -- Maximum n we'll consider
   MAX_N : constant := 1000000;
   
   -- dp[i] will store the number of ways to represent i
   dp : array (0 .. MAX_N) of Long_Integer;
   
   function Count_Ways(n : Long_Integer) return Long_Integer is
      result : Long_Integer := 0;
   begin
      -- Initialize dp array
      for i in 0 .. MAX_N loop
         dp(i) := 0;
      end loop;
      
      -- Base case
      dp(0) := 1;
      
      -- For each power of 2 (1, 2, 4, 8, ...)
      declare
         power : Long_Integer := 1;
      begin
         while power <= n loop
            -- For each number from power to n
            for i in power .. n loop
               -- We can use this power either 0, 1, or 2 times
               -- But we only add the cases where we use it 1 or 2 times
               -- (0 times is already handled by previous state)
               dp(i) := dp(i) + dp(i - power);
               
               -- If power > 1 and i >= 2 * power, we can also use it twice
               if power > 1 and then i >= 2 * power then
                  dp(i) := dp(i) + dp(i - 2 * power);
               end if;
            end loop;
            
            power := power * 2;
         end loop;
      end;
      
      return dp(n);
   end Count_Ways;
   
   -- More efficient approach using inclusion-exclusion or direct DP
   function Count_Ways_Efficient(n : Long_Integer) return Long_Integer is
      result : Long_Integer := 0;
   begin
      -- Initialize dp array
      for i in 0 .. MAX_N loop
         dp(i) := 0;
      end loop;
      
      dp(0) := 1;
      
      -- For each power of 2, up to the maximum needed
      declare
         p : Long_Integer := 1;
         max_power : constant Long_Integer := 2**30;  -- Large enough
      begin
         while p <= n and then p <= max_power loop
            -- Process from right to left to avoid counting same power multiple times
            for i in reverse p .. n loop
               -- Add ways using this power once
               dp(i) := dp(i) + dp(i - p);
               
               -- Add ways using this power twice (if applicable)
               if i >= 2 * p then
                  dp(i) := dp(i) + dp(i - 2 * p);
               end if;
            end loop;
            
            p := p * 2;
         end loop;
      end;
      
      return dp(n);
   end Count_Ways_Efficient;
   
   -- Simpler approach using direct recurrence
   function Count_Ways_Simple(n : Long_Integer) return Long_Integer is
      result : Long_Integer := 0;
   begin
      -- dp[i] = number of ways to make i
      for i in 0 .. MAX_N loop
         dp(i) := 0;
      end loop;
      
      dp(0) := 1;
      
      -- For each power of 2, from 1 to the largest needed
      declare
         power : Long_Integer := 1;
      begin
         while power <= n loop
            -- For each number from power to n
            for i in power .. n loop
               -- We can use this power either once or twice
               dp(i) := dp(i) + dp(i - power);
               if i >= 2 * power then
                  dp(i) := dp(i) + dp(i - 2 * power);
               end if;
            end loop;
            
            power := power * 2;
         end loop;
      end;
      
      return dp(n);
   end Count_Ways_Simple;

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO;

procedure Euler_396 is
   type Long_Integer is range -2**63 .. 2**63-1;
   
   -- The problem asks for the number of ways to write n as a sum 
   -- of powers of 2 where each power can be used at most twice
   
   MAX_N : constant := 1000000;
   
   dp : array (0 .. MAX_N) of Long_Integer;
   
   function Count_Ways(n : Long_Integer) return Long_Integer is
      power : Long_Integer;
   begin
      -- Initialize dp array to zero
      for i in 0 .. MAX_N loop
         dp(i) := 0;
      end loop;
      
      -- Base case: one way to make 0 (use nothing)
      dp(0) := 1;
      
      -- Process each power of 2 from 1 upward
      power := 1;
      while power <= n loop
         -- For each number that can use this power
         for i in power .. n loop
            -- Add ways using this power once
            dp(i) := dp(i) + dp(i - power);
            
            -- Add ways using this power twice (if possible)
            if i >= 2 * power then
               dp(i) := dp(i) + dp(i - 2 * power);
            end if;
         end loop;
         
         power := power * 2;
      end loop;
      
      return dp(n);
   end Count_Ways;
   
begin
   -- Calculate the answer for n = 1000000
   Put("Answer for n=1000000: ");
   Put(Count_Ways(1000000), 0);
   New_Line;
end Euler_396;
```

This solution uses dynamic programming where:
1. `dp[i]` represents the number of ways to represent integer `i`
2. For each power of 2 (1, 2, 4, 8, ...), we update all possible sums
3. When we process power `p`, we can use it either once or twice in our representation
4. The recurrence maintains that each power can be used at most twice

The time complexity is O(n log n) and space complexity is O(n).
