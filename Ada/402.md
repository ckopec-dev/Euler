# Euler Problem 402 Solution in Ada

## Problem Statement
Euler Problem 402 asks us to find the sum of all numbers n ≤ 10^15 such that φ(n) is a perfect square, where φ(n) is Euler's totient function.

## Analysis
This is a complex number theory problem. We need to:
1. Calculate Euler's totient function φ(n)
2. Check if φ(n) is a perfect square
3. Sum all such n up to 10^15

However, given the large constraint (n ≤ 10^15), we need an efficient approach rather than brute force.

## Key Insights
- For φ(n) to be a perfect square, we need to understand the structure of n
- If n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then φ(n) = n × ∏(1 - 1/pᵢ)
- This leads to a specific form that makes φ(n) a perfect square
