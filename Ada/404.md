   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then

      else
         for I in 3 .. Root loop
            if N mod I = 0 then

            end if;
         end loop;
         return True;
      end if;

   -- Function to calculate a(n) = n² + n + 41
   function A_N(N : Natural) return Natural is

      return N * N + N + 41;
   end A_N;
   
   -- Main solution

The solution works by:
1. Generating values of a(n) = n² + n + 41 for increasing values of n
2. Checking if each value is prime using the Is_Prime function
3. Summing up all prime values that are less than 10^8
4. Stopping when a(n) reaches or exceeds 10^8

The key insight is that we only need to consider distinct prime values, and since we're iterating through n in order, we naturally get distinct values (though many will not be prime). The solution efficiently computes the sum of all such prime numbers generated by this quadratic formula.
