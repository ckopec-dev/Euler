# Euler Problem 407 Solution in Ada

Euler Problem 407 asks us to find the sum of all numbers n ≤ 10^7 such that n² ≡ n (mod φ(n)), where φ(n) is Euler's totient function.

Let me solve this step by step:

## Analysis

The condition n² ≡ n (mod φ(n)) can be rewritten as:
n² - n ≡ 0 (mod φ(n))
n(n-1) ≡ 0 (mod φ(n))

This means φ(n) divides n(n-1).

## Approach

1. For each number n from 1 to 10^7, we need to compute φ(n)
2. Check if φ(n) divides n(n-1)
3. Sum all such numbers

However, computing φ(n) for each n separately would be too slow. Instead, I'll use the fact that we can compute φ(n) efficiently using prime factorization.

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_407 is
   
   type Integer_Array is array (Positive range <>) of Natural;
   
   -- Compute Euler's totient function φ(n)
   function Phi(n : Natural) return Natural is
      result : Natural := n;
      temp_n : Natural := n;
      i : Natural := 2;
   begin
      if n = 0 then
         return 0;
      end if;
      
      while i * i <= temp_n loop
         if temp_n mod i = 0 then
            result := result - result / i;
            while temp_n mod i = 0 loop
               temp_n := temp_n / i;
            end loop;
         end if;
         i := i + 1;
      end loop;
      
      if temp_n > 1 then
         result := result - result / temp_n;
      end if;
      
      return result;
   end Phi;
   
   -- Check if n² ≡ n (mod φ(n))
   function Is_Valid(n : Natural) return Boolean is
      phi_n : constant Natural := Phi(n);
   begin
      if phi_n = 0 then
         return False;
      end if;
      
      -- Check if φ(n) divides n(n-1)
      return (n * (n - 1)) mod phi_n = 0;
   end Is_Valid;
   
   -- Main computation
   limit : constant Natural := 10_000_000;
   total_sum : Natural := 0;
   
begin
   Put_Line("Computing sum for n ≤ " & Integer'Image(limit));
   
   for i in 1..limit loop
      if Is_Valid(i) then
         total_sum := total_sum + i;
      end if;
      
      -- Progress indicator
      if i mod 1_000_000 = 0 then
         Put_Line("Processed: " & Integer'Image(i));
      end if;
   end loop;
   
   Put_Line("Sum of all valid numbers: " & Natural'Image(total_sum));
end Euler_407;

with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_407 is
   
   limit : constant Integer := 10_000_000;
   
   -- Array to store totient values (φ(n))
   type Totient_Array is array (Integer range 0..limit) of Integer;
   phi : Totient_Array;
   
   -- Sieve method to compute Euler's totient function
   procedure Compute_Totient is
      i, j : Integer;
   begin
      -- Initialize phi(n) = n for all n
      for i in 0..limit loop
         phi(i) := i;
      end loop;
      
      -- Apply sieve method
      for i in 2..limit loop
         if phi(i) = i then  -- i is prime
            for j in i..limit by i loop
               phi(j) := phi(j) - phi(j) / i;
            end loop;
         end if;
      end loop;
   end Compute_Totient;
   
   -- Check if n² ≡ n (mod φ(n))
   function Is_Valid(n : Integer) return Boolean is
      phi_n : constant Integer := phi(n);
   begin
      -- Special case: phi(0) = 0, but we don't consider n=0
      if phi_n = 0 then
         return False;
      end if;
      
      -- Check if φ(n) divides n(n-1)
      return (n * (n - 1)) mod phi_n = 0;
   end Is_Valid;
   
   total_sum : Integer := 0;
   
begin
   Put_Line("Computing totient function for all numbers up to " & 
            Integer'Image(limit));
   
   Compute_Totient;
   
   Put_Line("Checking condition n² ≡ n (mod φ(n))...");
   
   for i in 1..limit loop
      if Is_Valid(i) then
         total_sum := total_sum + i;
      end if;
      
      -- Progress indicator
      if i mod 1_000_000 = 0 then
         Put_Line("Processed: " & Integer'Image(i));
      end if;
   end loop;
   
   Put_Line("Sum of all valid numbers: " & Integer'Image(total_sum));
end Euler_407;

1. **Totient Function Computation**: Uses the sieve method to efficiently compute φ(n) for all n up to 10^7
2. **Condition Check**: For each number n, checks if φ(n) divides n(n-1) 
3. **Summation**: Accumulates all valid numbers
