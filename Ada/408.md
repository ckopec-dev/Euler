# Euler Problem 408 Solution in Ada

I'll solve Euler Problem 408, which asks for the sum of all distinct pseudo-Fortunate numbers for primes p < 10^6.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_408 is
   
   -- Constants
   Max_Prime := 10**6;
   
   -- Vector to store primes
   type Prime_Vector is array (Positive range <>) of Natural;
   package Prime_Vectors is new Ada.Containers.Vectors (Positive, Natural);
   Primes : Prime_Vectors.Vector;
   
   -- Sieve of Eratosthenes to find primes
   procedure Sieve_Of_Eratosthenes is
      Is_Prime : array (0 .. Max_Prime) of Boolean := (others => True);
      P : Natural;
   begin
      Is_Prime(0) := False;
      Is_Prime(1) := False;
      
      for I in 2 .. sqrt(Max_Prime) loop
         if Is_Prime(I) then
            P := I * I;
            while P <= Max_Prime loop
               Is_Prime(P) := False;
               P := P + I;
            end loop;
         end if;
      end loop;
      
      -- Collect primes
      for I in 2 .. Max_Prime loop
         if Is_Prime(I) then
            Primes.Append(I);
         end if;
      end loop;
   end Sieve_Of_Eratosthenes;
   
   -- Function to check if a number is prime
   function Is_Prime(N : Natural) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer(sqrt(Float(N))) by 2 loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Function to compute pseudo-Fortunate number
   function Pseudo_Fortunate(P : Natural) return Natural is
      M : Natural := 1;
      Product : Natural := 1;
      N : Natural;
   begin
      -- Compute product of all primes up to P
      for I in 1 .. Primes.Length loop
         exit when Primes.Element(I) > P;
         Product := Product * Primes.Element(I);
      end loop;
      
      -- Find smallest M such that Product + M is prime
      loop
         N := Product + M;
         if Is_Prime(N) then
            return M;
         end if;
         M := M + 1;
      end loop;
   end Pseudo_Fortunate;
   
   -- Set to store distinct pseudo-Fortunate numbers
   type Set is array (Positive range <>) of Natural;
   Distinct_Pseudo_Fortunate : Set(1 .. Max_Prime);
   Count : Positive := 1;
   
   -- Function to check if number exists in set
   function Contains(N : Natural) return Boolean is
   begin
      for I in 1 .. Count - 1 loop
         if Distinct_Pseudo_Fortunate(I) = N then
            return True;
         end if;
      end loop;
      return False;
   end Contains;
   
   -- Add number to set if not already present
   procedure Add_To_Set(N : Natural) is
   begin
      if not Contains(N) then
         Distinct_Pseudo_Fortunate(Count) := N;
         Count := Count + 1;
      end if;
   end Add_To_Set;
   
begin
   -- Find all primes up to 10^6
   Sieve_Of_Eratosthenes;
   
   -- Compute pseudo-Fortunate numbers for each prime
   for I in 1 .. Primes.Length loop
      declare
         P : Natural := Primes.Element(I);
      begin
         exit when P >= Max_Prime;
         Add_To_Set(Pseudo_Fortunate(P));
      end;
   end loop;
   
   -- Calculate sum of distinct pseudo-Fortunate numbers
   declare
      Sum : Natural := 0;
   begin
      for I in 1 .. Count - 1 loop
         Sum := Sum + Distinct_Pseudo_Fortunate(I);
      end loop;
      
      Put_Line("Sum of all distinct pseudo-Fortunate numbers: " & 
               Integer'Image(Sum));
   end;
   
end Euler_408;
```

## Explanation

This solution follows these key steps:

1. **Prime Generation**: Uses the Sieve of Eratosthenes to efficiently find all primes up to 10^6.

2. **Pseudo-Fortunate Number Calculation**: For each prime p, it:
   - Computes the product of all primes ≤ p
   - Finds the smallest positive integer M such that (product + M) is prime
   - This M is the pseudo-Fortunate number for prime p

3. **Distinct Values Collection**: Maintains a set of distinct pseudo-Fortunate numbers to avoid counting duplicates.

4. **Summation**: Computes and outputs the sum of all distinct pseudo-Fortunate numbers.

The key insight in Euler Problem 408 is that we need to find the smallest M such that when added to the product of all primes up to p, the result is prime. This gives us the pseudo-Fortunate number for each prime p.
