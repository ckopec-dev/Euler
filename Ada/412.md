# Euler Problem 412 Solution in Ada

## Problem Statement
We are given a game where two players take turns removing stones from piles. The first player removes stones, and then players alternate turns. On each turn, a player can remove any positive number of stones from a single pile, but cannot remove all stones from a pile if there are other non-empty piles. A player who cannot make a move loses.

We need to find the number of winning positions for the first player when there are 3 piles with 1, 2, and 3 stones respectively.

## Solution Approach
This is a classic game theory problem that can be solved using the Sprague-Grundy theorem. We need to:
1. Calculate the Grundy number (nimber) for each position
2. Determine if the initial position is winning or losing for the first player

   -- Function to calculate Grundy number using memoization

      mex : Integer;

      end if;
      
      -- Base case: all piles empty
      if p1 = 0 and p2 = 0 and p3 = 0 then
         return 0;
      end if;
      
      -- Calculate XOR of Grundy numbers of subpositions
      xor_result := 0;
      
      -- Try all possible moves from this position
      declare
         next_positions : array (1..100) of Position;
         count : Integer := 0;
      begin
         -- Generate all possible next positions
         for i in 1..p1 loop
            if p1 > i or p2 > 0 or p3 > 0 then
               count := count + 1;
               next_positions(count) := (p1 - i, p2, p3);
            end if;
         end loop;

            if p1 > 0 or p2 > i or p3 > 0 then
               count := count + 1;
               next_positions(count) := (p1, p2 - i, p3);
            end if;
         end loop;

            if p1 > 0 or p2 > 0 or p3 > i then
               count := count + 1;
               next_positions(count) := (p1, p2, p3 - i);
            end if;
         end loop;
         
         -- Calculate mex of all possible moves
         declare
            grundy_values : array (0..100) of Boolean := (others => False);
         begin
            for i in 1..count loop
               declare
                  next_grundy : constant Integer := Grundy(next_positions(i));
               begin
                  if next_grundy < 100 then
                     grundy_values(next_grundy) := True;
                  end if;
               end;
            end loop;
            
            -- Find minimum excludant (mex)
            mex := 0;
            while mex < 100 and grundy_values(mex) loop
               mex := mex + 1;
            end loop;
         end;
      end;
