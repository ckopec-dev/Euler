# Euler Problem 413 Solution in Ada

I'll solve Euler Problem 413, which asks for the sum of all integers from 1 to n that are divisible by at least one of the numbers 2, 3, 5, or 7.

## Problem Analysis

We need to find the sum of integers from 1 to n that are divisible by at least one of {2, 3, 5, 7}. This is a classic inclusion-exclusion principle problem.

## Solution Approach

I'll use the inclusion-exclusion principle:
- Add sums of multiples of each prime
- Subtract sums of multiples of pairs of primes  
- Add sums of multiples of triplets of primes
- Subtract sums of multiples of all four primes

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_413 is
   
   -- Function to calculate sum of multiples of d from 1 to n
   function Sum_Multiples(d : Integer; n : Integer) return Long_Long_Integer is
      k : constant Integer := n / d;
   begin
      return Long_Long_Integer(k) * Long_Long_Integer(k + 1) * Long_Long_Integer(d) / 2;
   end Sum_Multiples;
   
   -- Function to calculate GCD of two numbers
   function GCD(a, b : Integer) return Integer is
   begin
      if b = 0 then
         return a;
      else
         return GCD(b, a mod b);
      end if;
   end GCD;
   
   -- Function to calculate LCM of two numbers
   function LCM(a, b : Integer) return Integer is
   begin
      return a * b / GCD(a, b);
   end LCM;
   
   -- Function to calculate LCM of multiple numbers using inclusion-exclusion
   function Solve(n : Integer) return Long_Long_Integer is
      primes : array(1..4) of Integer := (2, 3, 5, 7);
      result : Long_Long_Integer := 0;
      sign : Integer := 1;
      num_primes : constant Integer := 4;
   begin
      -- Generate all non-empty subsets using bit manipulation
      for mask in 1..(2**num_primes - 1) loop
         declare
            lcm_val : Integer := 1;
            count : Integer := 0;
         begin
            for i in 1..num_primes loop
               if (mask and (2**(i-1))) /= 0 then
                  lcm_val := LCM(lcm_val, primes(i));
                  count := count + 1;
               end if;
            end loop;
            
            -- Apply inclusion-exclusion principle
            if count mod 2 = 1 then
               sign := 1;
            else
               sign := -1;
            end if;
            
            result := result + sign * Sum_Multiples(lcm_val, n);
         end;
      end loop;
      
      return result;
   end Solve;
   
   -- Test with example values
   test_n : constant Integer := 1000000;
begin
   Put("Sum of integers from 1 to ");
   Put(test_n, Width => 0);
   Put(" divisible by at least one of {2, 3, 5, 7}: ");
   
   declare
      answer : Long_Long_Integer := Solve(test_n);
   begin
      Put(answer, Width => 0);
      New_Line;
   end;
end Euler_413;
```

## Explanation

The solution uses the inclusion-exclusion principle:

1. **Sum of multiples**: For a divisor `d` and range up to `n`, the sum is `d × k(k+1)/2` where `k = n/d`

2. **Inclusion-Exclusion Principle**:
   - Add: multiples of 2, 3, 5, 7
   - Subtract: multiples of 6(2×3), 10(2×5), 14(2×7), 15(3×5), 21(3×7), 35(5×7)  
   - Add: multiples of 30(2×3×5), 42(2×3×7), 70(2×5×7), 105(3×5×7)
   - Subtract: multiples of 210(2×3×5×7)

3. **Bit manipulation**: Generate all non-empty subsets of {2, 3, 5, 7} to determine which LCMs to include

## Key Features

- Uses `Long_Long_Integer` for handling large sums
- Implements GCD and LCM functions for proper calculation
- Applies inclusion-exclusion principle correctly
- Efficient bit manipulation approach to generate subsets

The algorithm has time complexity O(2^4) = O(1) since we have a fixed number of primes, making it very efficient for the given problem.
