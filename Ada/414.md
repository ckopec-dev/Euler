## Problem Understanding

Euler Problem 414 asks us to find the number of ways to write n as a sum of powers of 2, where each power can be used at most twice. This is equivalent to finding the number of partitions of n using parts that are powers of 2, with each part appearing at most twice.

## Solution Approach

We'll use dynamic programming where:
- `dp[i]` = number of ways to represent integer i
- For each power of 2 (1, 2, 4, 8, ...), we update our dp array
- Each power can be used 0, 1, or 2 times

   function Count_Ways (N : Long_Long_Integer) return Long_Long_Integer is
      Result : Long_Long_Integer := 0;

            Power : constant Long_Long_Integer := Powers_Of_2(P);

            -- Only process if this power is within range
