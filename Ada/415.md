# Euler Problem 415 Solution in Ada

This problem asks us to find the number of ways to tile a 3×n rectangle with 2×1 dominoes, where we can rotate the dominoes.

Let me break down the approach:
- We need to count tilings of a 3×n grid using 2×1 dominoes (which can be placed horizontally or vertically)
- This is a classic dynamic programming problem
- We'll use states representing different configurations of the last column

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_415 is
   MODULUS : constant Long_Long_Integer := 10**9 + 7;
   
   type Matrix_2x2 is array (0 .. 1, 0 .. 1) of Long_Long_Integer;
   
   function Matrix_Multiply(A, B : Matrix_2x2) return Matrix_2x2 is
      C : Matrix_2x2;
   begin
      for I in 0 .. 1 loop
         for J in 0 .. 1 loop
            C(I, J) := 0;
            for K in 0 .. 1 loop
               C(I, J) := (C(I, J) + A(I, K) * B(K, J)) mod MODULUS;
            end loop;
         end loop;
      end loop;
      return C;
   end Matrix_Multiply;
   
   function Matrix_Power(Mat : Matrix_2x2; Power : Long_Long_Integer) return Matrix_2x2 is
      Result : Matrix_2x2 := ((1, 0), (0, 1)); -- Identity matrix
      Base : Matrix_2x2 := Mat;
      P : Long_Long_Integer := Power;
   begin
      while P > 0 loop
         if P mod 2 = 1 then
            Result := Matrix_Multiply(Result, Base);
         end if;
         Base := Matrix_Multiply(Base, Base);
         P := P / 2;
      end loop;
      return Result;
   end Matrix_Power;
   
   function Tiling_Count(N : Long_Long_Integer) return Long_Long_Integer is
      -- For a 3×n rectangle, the recurrence is: T(n) = 4*T(n-1) - T(n-2)
      -- Base cases: T(0) = 1, T(1) = 3
      Result : Long_Long_Integer;
      
      -- Matrix exponentiation approach for large N:
      -- [T(n)]   [4 -1] [T(n-1)]
      -- [T(n-1)] = [1  0] [T(n-2)]
      
      Base_Matrix : Matrix_2x2 := ((4, -1), (1, 0));
      Result_Matrix : Matrix_2x2;
   begin
      if N = 0 then
         return 1;
      elsif N = 1 then
         return 3;
      else
         Result_Matrix := Matrix_Power(Base_Matrix, N - 1);
         
         -- T(N) = Result_Matrix(0,0) * T(1) + Result_Matrix(0,1) * T(0)
         Result := (Result_Matrix(0, 0) * 3 + Result_Matrix(0, 1) * 1) mod MODULUS;
         
         -- Handle negative result from modular arithmetic
         if Result < 0 then
            Result := Result + MODULUS;
         end if;
         
         return Result;
      end if;
   end Tiling_Count;

begin
   -- Compute the result for n = 10^16
   Put_Line("Result: ");
   Put(Tiling_Count(10**16));
   New_Line;
end Euler_415;
```

This solution uses matrix exponentiation to efficiently compute the result for very large values of n (up to 10^16). The key insight is that the recurrence relation T(n) = 4*T(n-1) - T(n-2) can be represented using matrix multiplication, which allows us to compute the answer in O(log N) time instead of O(N).
