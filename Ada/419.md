# Euler Problem 419 Solution in Ada

I'll solve Project Euler Problem 419, which asks for the sum of all integers k such that the number of divisors of k^2 is exactly 2000.

## Problem Analysis

We need to find all positive integers k where d(k²) = 2000, where d(n) is the number of divisors of n.

If k has prime factorization k = p₁^a₁ × p₂^a₂ × ... × pₘ^aₘ, then:
- k² = p₁^(2a₁) × p₂^(2a₂) × ... × pₘ^(2aₘ)
- d(k²) = (2a₁ + 1)(2a₂ + 1)...(2aₘ + 1) = 2000

We need to find all possible ways to express 2000 as a product of odd factors, then determine the corresponding values of k.

## Solution Approach

1. Find all factorizations of 2000 into odd factors
2. For each factorization, determine the exponents in k's prime factorization
3. Generate all valid k values (up to reasonable bounds)
4. Sum all such k values
