# Euler Problem 420 Solution in Ada

Euler Problem 420 asks us to find the sum of all positive integers n ≤ 10^17 for which φ(n) + σ(n) = n + 1, where φ is Euler's totient function and σ is the divisor function.

Let me analyze this problem step by step:

## Mathematical Analysis

The equation φ(n) + σ(n) = n + 1 can be rewritten as:
φ(n) + σ(n) - n - 1 = 0

For a prime p, we have:
- φ(p) = p - 1
- σ(p) = p + 1
- So φ(p) + σ(p) = (p - 1) + (p + 1) = 2p = p + p = p + (p + 1) - 1 = n + σ(n) - 1

This means for primes, we get: φ(p) + σ(p) = n + 1, which satisfies our equation.
