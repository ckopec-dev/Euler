## Problem Analysis

We need to find all integers n ≤ 10^12 such that φ(n) divides n, then sum them all up.

Key insights:
- If φ(n) divides n, then n/φ(n) must be an integer
- For a prime p, φ(p) = p-1, so we need (p-1)|p, which means p-1|p, so p-1|1, so p=2

- We need to check all numbers of the form 2^a × 3^b × 5^c × ... where each prime p contributes to making n/φ(n) an integer
