# Euler Problem 428 Solution in Ada

I'll solve Project Euler Problem 428, which asks for the sum of all positive integers n ≤ 10^17 such that τ(n) is odd, where τ(n) is the number of divisors of n.

## Problem Analysis

The key insight is that τ(n) is odd if and only if n is a perfect square. This is because:
- For a number n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, we have τ(n) = (a₁+1)(a₂+1)...(aₖ+1)
- For τ(n) to be odd, each factor (aᵢ+1) must be odd
- This means each aᵢ must be even
- Therefore n must be a perfect square

So we need to find all perfect squares ≤ 10^17 and sum them.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_428 is
   type Large_Integer is range 0 .. 10**17;
   
   Limit : constant Large_Integer := 10**17;
   Total_Sum : Large_Integer := 0;
   Square : Large_Integer := 1;
   Counter : Large_Integer := 1;
   
begin
   -- Find all perfect squares up to the limit
   while Square <= Limit loop
      Total_Sum := Total_Sum + Square;
      Counter := Counter + 1;
      Square := Counter * Counter;
   end loop;
   
   Put("Sum of all perfect squares <= 10^17: ");
   Put(Total_Sum);
   New_Line;
end Euler_428;
```

## Mathematical Approach

However, since we're dealing with perfect squares, there's a more efficient mathematical approach using the formula for sum of squares:

For perfect squares from 1² to k² where k² ≤ N:
- The number of perfect squares ≤ N is floor(√N)
- Sum = 1² + 2² + 3² + ... + k² = k(k+1)(2k+1)/6

Let's implement a more mathematically efficient version:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_428 is
   type Large_Integer is range 0 .. 10**17;
   
   Limit : constant Large_Integer := 10**17;
   
   -- Calculate floor of square root of limit
   function Sqrt_Int(N : Large_Integer) return Large_Integer is
      X : Large_Integer := N;
      Y : Large_Integer := (N + 1) / 2;
   begin
      while Y < X loop
         X := Y;
         Y := (X + N / X) / 2;
      end loop;
      return X;
   end Sqrt_Int;
   
   -- Sum of squares from 1 to k: k(k+1)(2k+1)/6
   function Sum_Of_Squares(K : Large_Integer) return Large_Integer is
   begin
      return K * (K + 1) * (2 * K + 1) / 6;
   end Sum_Of_Squares;
   
   K : constant Large_Integer := Sqrt_Int(Limit);
   Result : Large_Integer;
   
begin
   Result := Sum_Of_Squares(K);
   
   Put("Sum of all perfect squares <= 10^17: ");
   Put(Result);
   New_Line;
end Euler_428;
```

## Explanation

The solution works as follows:

1. **Key Insight**: τ(n) is odd if and only if n is a perfect square
2. **Mathematical Formula**: The sum of first k perfect squares is k(k+1)(2k+1)/6
3. **Finding k**: We need to find the largest integer k such that k² ≤ 10^17
4. **Calculation**: Apply the formula with k = floor(√10^17)

## Verification

For a limit of 10^17:
- √10^17 ≈ 3.16 × 10^8
- So k = 316,227,766 (approximately)
- Sum = k(k+1)(2k+1)/6

The Ada code efficiently computes this using the mathematical approach rather than iterating through all numbers.
