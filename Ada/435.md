# Euler Problem 435 Solution in Ada

I'll solve Euler Problem 435, which asks for the sum of the squares of Fibonacci numbers modulo a given number.

## Problem Statement
Find the sum of S(n) = F₁² + F₂² + ... + Fₙ² where Fᵢ is the i-th Fibonacci number, modulo 10⁹ + 7.

## Solution Approach

I'll use the mathematical property that S(n) = Fₙ × Fₙ₊₁, which can be proven using Cassini's identity.

   function Modular_Multiply(A, B : in Long_Long_Integer) return Long_Long_Integer is
   begin
      return (A * B) mod MODULO;
   end Modular_Multiply;

   begin
      return (A + B) mod MODULO;
   end Modular_Add;

         return 0;

         return 1;

            Temp := Modular_Add(F1, F2);
            F1 := F2;
            F2 := Temp;
         end loop;
         
         -- The sum of squares of first N Fibonacci numbers is F(N) * F(N+1)
         Result := Modular_Multiply(F1, F2);
         return Result;
      end if;
   end Fibonacci_Sum_Squares;

         return C;
      end Matrix_Multiply;

               Result := Matrix_Multiply(Result, Base);
