# Euler Problem 451 Solution in Ada

This problem asks us to find the sum of all values of n such that φ(n) = φ(n+1) = φ(n+2), where φ is Euler's totient function.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_451 is
   
   -- Function to compute greatest common divisor
   function GCD(A, B : Integer) return Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Function to compute Euler's totient function φ(n)
   function Totient(N : Integer) return Integer is
      Count : Integer := 0;
   begin
      for I in 1..N loop
         if GCD(I, N) = 1 then
            Count := Count + 1;
         end if;
      end loop;
      return Count;
   end Totient;
   
   -- Function to check if φ(n) = φ(n+1) = φ(n+2)
   function Check_Totient_Three(N : Integer) return Boolean is
      T1, T2, T3 : Integer;
   begin
      T1 := Totient(N);
      T2 := Totient(N + 1);
      T3 := Totient(N + 2);
      
      return T1 = T2 and T2 = T3;
   end Check_Totient_Three;
   
   -- Main computation
   Sum : Integer := 0;
   Limit : constant Integer := 3000000;
   
begin
   for N in 1..Limit loop
      if Check_Totient_Three(N) then
         Sum := Sum + N;
         Put_Line("Found: " & Integer'Image(N));
      end if;
   end loop;
   
   Put_Line("Sum = " & Integer'Image(Sum));
end Euler_451;
```
