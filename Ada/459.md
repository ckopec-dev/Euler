## Problem Understanding

Euler Problem 459 asks us to find the number of ordered pairs (a,b) such that:
- a and b are positive integers
- a < b
- a + b = n
- gcd(a,b) = 1

This is equivalent to finding the number of coprime pairs (a,b) where a + b = n and a < b.

## Mathematical Analysis

For a + b = n with a < b:
- Since a < b and both are positive, we have a < n/2
- Also, since a + b = n, we have b = n - a
- For a < b: a < n - a, so 2a < n, thus a < n/2

The number of such pairs where gcd(a, n-a) = 1 equals the number of integers a such that:
1. 1 ≤ a < n/2
2. gcd(a, n-a) = 1
