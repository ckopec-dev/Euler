# Euler Problem 460 Solution in Ada

I'll solve Euler Problem 460, which asks for the sum of all distinct values of f(n) where f(n) = n^2 + n + 41 and n ranges from 0 to 39.

Let me break this down:
- We need to compute f(n) = n² + n + 41 for n = 0, 1, 2, ..., 39
- Find all distinct values of these computations
- Sum all the distinct values

Here's my Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_460 is
   type Integer_Array is array (Natural range <>) of Integer;
   
   -- Function to compute f(n) = n^2 + n + 41
   function F(N : Integer) return Integer is
   begin
      return N * N + N + 41;
   end F;
   
   -- Array to store all values
   Values : array (0 .. 39) of Integer;
   
   -- Set to track distinct values
   type Boolean_Array is array (Integer range <>) of Boolean;
   Distinct_Values : array (Integer range -1000 .. 1000) of Boolean := (others => False);
   
   Sum : Integer := 0;
   
begin
   -- Compute all f(n) values for n from 0 to 39
   for N in 0 .. 39 loop
      Values(N) := F(N);
   end loop;
   
   -- Find distinct values and sum them
   for N in 0 .. 39 loop
      if not Distinct_Values(Values(N)) then
         Distinct_Values(Values(N)) := True;
         Sum := Sum + Values(N);
      end if;
   end loop;
   
   Put_Line("Sum of all distinct values: ");
   Put(Sum, Width => 1);
   New_Line;
   
end Euler_460;
```
