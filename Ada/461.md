# Euler Problem 461 Solution in Ada

## Problem Statement
The problem asks us to find the number of integer quadruples (a,b,c,d) such that:
- a² + b² + c² + d² = n for some positive integer n
- a, b, c, d are all positive integers
- a ≤ b ≤ c ≤ d

## Solution Approach
We'll use a two-pointer technique:
1. Generate all possible sums of squares a² + b² for a ≤ b
2. Generate all possible sums of squares c² + d² for c ≤ d  
3. For each sum from step 1, find matching sums from step 2 that add up to n
4. Count valid combinations

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_461 is
   type Square_Array is array (Positive range <>) of Positive;
   
   -- Generate all possible sums of two squares a² + b² where a ≤ b
   function Generate_Sums(n : Positive) return Square_Array is
      Result : Square_Array(1..n * n);
      Count  : Positive := 1;
   begin
      for a in 1..n loop
         for b in a..n loop
            if a*a + b*b <= n then
               Result(Count) := a*a + b*b;
               Count := Count + 1;
            end if;
         end loop;
      end loop;
      
      -- Return only the valid portion
      return Result(1..Count-1);
   end Generate_Sums;
   
   function Count_Quadruples(n : Positive) return Natural is
      -- Precompute all sums a² + b² where a ≤ b
      Sum_AB : Square_Array := Generate_Sums(n);
      
      -- Precompute all sums c² + d² where c ≤ d  
      Sum_CD : Square_Array := Generate_Sums(n);
      
      Count : Natural := 0;
      i, j : Positive := 1;
   begin
      -- Two-pointer approach: for each sum from AB, find matching sums from CD
      i := 1;
      j := Sum_CD'Last;
      
      while i <= Sum_AB'Last and j >= 1 loop
         declare
            Total : Positive := Sum_AB(i) + Sum_CD(j);
         begin
            if Total = n then
               Count := Count + 1;
               i := i + 1;
               j := j - 1;
            elsif Total < n then
               i := i + 1;
            else
               j := j - 1;
            end if;
         end;
      end loop;
      
      return Count;
   end Count_Quadruples;
