# Euler Problem 467 Solution in Ada

I'll solve Euler Problem 467, which asks for the number of ways to write a number as a sum of distinct Fibonacci numbers.

First, let me understand what the problem is asking:
- Find the number of ways to express a given number as a sum of distinct Fibonacci numbers
- Each Fibonacci number can be used at most once

## Solution Approach

I'll use dynamic programming where I build up the solution by considering each Fibonacci number and how it contributes to forming different sums.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_467 is
   
   -- Maximum value we need to consider
   MAX_N : constant := 10**12;
   
   -- Fibonacci numbers up to a reasonable limit
   type Fibonacci_Array is array (1..100) of Long_Long_Integer;
   Fib : Fibonacci_Array;
   Fib_Count : Natural := 0;
   
   -- Dynamic programming array to count ways
   type Ways_Array is array (0..Long_Long_Integer'Last) of Long_Long_Integer;
   Ways : Ways_Array := (others => 0);
   
   -- Function to generate Fibonacci numbers up to MAX_N
   procedure Generate_Fibonacci is
      F1, F2 : Long_Long_Integer := 1;
      Index : Natural := 1;
   begin
      Fib(Index) := F1;
      Index := Index + 1;
      Fib(Index) := F2;
      Index := Index + 1;
      
      loop
         declare
            Next : constant Long_Long_Integer := F1 + F2;
         begin
            if Next > MAX_N then
               exit;
            end if;
            
            Fib(Index) := Next;
            Index := Index + 1;
            F1 := F2;
            F2 := Next;
         end;
      end loop;
      
      Fib_Count := Index - 1;
   end Generate_Fibonacci;
   
   -- Main computation
   procedure Compute_Solution is
      N : constant Long_Long_Integer := 10**12;
   begin
      -- Initialize ways array
      Ways(0) := 1;  -- One way to make 0 (use nothing)
      
      -- For each Fibonacci number, update the ways array
      for I in 1..Fib_Count loop
         declare
            F : constant Long_Long_Integer := Fib(I);
         begin
            -- Process from high to low to avoid double counting
            for J in reverse F..N loop
               if Ways(J - F) > 0 then
                  Ways(J) := Ways(J) + Ways(J - F);
               end if;
            end loop;
         end;
      end loop;
      
      Put("Number of ways to express ");
      Put(N, 0);
      Put(" as sum of distinct Fibonacci numbers: ");
      Put(Ways(N), 0);
      New_Line;
   end Compute_Solution;

begin
   Generate_Fibonacci;
   Compute_Solution;
end Euler_467;
```

## Key Implementation Details

1. **Fibonacci Generation**: The program generates all Fibonacci numbers up to the required limit (10^12)

2. **Dynamic Programming Approach**: 
   - Uses a `Ways` array where `Ways[i]` represents the number of ways to form sum `i`
   - For each Fibonacci number, it updates the ways to form larger sums
   - Processes in reverse order to avoid counting the same Fibonacci number multiple times

3. **Efficiency Considerations**:
   - Only generates Fibonacci numbers up to the needed range
   - Uses long long integers to handle large numbers
   - Processes from high to low values to prevent double counting

## Mathematical Insight

This is essentially a variant of the subset sum problem where we're looking for the number of subsets of Fibonacci numbers that sum to our target. The key insight is that we can use dynamic programming with the constraint that each Fibonacci number can only be used once.

The solution has time complexity O(N × F) where N is the target number and F is the count of Fibonacci numbers less than or equal to N.

Note: Due to the large size of 10^12, this implementation might need optimization for very large inputs, but it demonstrates the core algorithmic approach to solving Euler Problem 467.
