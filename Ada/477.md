# Euler Problem 477 Solution in Ada

Euler Problem 477 asks us to find the sum of all distinct values of f(n) for n ≤ 10^8, where f(n) is defined as the number of ways to write n as a sum of consecutive positive integers.

Let me solve this step by step:

## Mathematical Analysis

For a number n, we want to count how many ways it can be expressed as:
n = a + (a+1) + (a+2) + ... + (a+k-1)

This simplifies to:
n = k*a + k*(k-1)/2
n = k*(2a + k - 1)/2
2n = k*(2a + k - 1)
2n/k = 2a + k - 1
(2n/k - k + 1)/2 = a

For this to be valid, we need:
1. 2n is divisible by k
2. (2n/k - k + 1) is even and positive
3. a ≥ 1

This means k must be a divisor of 2n, and (2n/k - k + 1) must be positive and even.
