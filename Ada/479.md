# Euler Problem 479 Solution in Ada

I'll solve Euler Problem 479, which asks for the sum of all integers k from 1 to 10^12 such that gcd(k, 30) = 1.

## Problem Understanding

We need to find the sum of all integers k where 1 ≤ k ≤ 10^12 and gcd(k, 30) = 1. Since 30 = 2 × 3 × 5, this means k must be coprime with 2, 3, and 5.

This is essentially finding the sum of all integers up to 10^12 that are not divisible by 2, 3, or 5.

## Approach

I'll use the inclusion-exclusion principle:
1. Find the count of numbers ≤ n that are coprime with 30
2. Find their sum using the formula for arithmetic series
3. Apply inclusion-exclusion to avoid overcounting

## Mathematical Analysis

The key insight is to use the inclusion-exclusion principle:
- Let A = multiples of 2, B = multiples of 3, C = multiples of 5
- We want numbers NOT in (A ∪ B ∪ C)
- Using inclusion-exclusion: |A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|

For sum of numbers up to n:
1. Total sum = n(n+1)/2
2. Sum of multiples of 2 = 2 × (n/2)(n/2+1)/2
3. And so on for 3, 5, etc.

The final result is: Total_sum - Sum_of_multiples
