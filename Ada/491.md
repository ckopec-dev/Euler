# Euler Problem 491 Solution in Ada

## Problem Statement
We call a positive integer **double pandigital** if it uses all digits 0-9 exactly twice (once in each of two pandigital numbers). How many double pandigital numbers are divisible by 11?

## Approach
This is a combinatorial problem that requires:
1. Understanding divisibility by 11 (alternating sum of digits = 0 mod 11)
2. Counting valid arrangements of digits 0-9 appearing twice each
3. Using dynamic programming or mathematical counting
