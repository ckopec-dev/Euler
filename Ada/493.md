# Euler Problem 493 Solution in Ada

I'll solve Project Euler problem 493 using Ada programming language. This problem asks for the expected number of distinct colors when drawing 20 balls from an urn containing 70 balls (10 of each of 7 different colors).

## Problem Analysis

We need to find the expected value of distinct colors when drawing 20 balls from 70 balls (10 of each color). This is a classic probability problem that can be solved using linearity of expectation.

Let's define indicator random variables for each color:
- Let Xᵢ = 1 if color i appears at least once in the draw
- Let Xᵢ = 0 otherwise

The expected number of distinct colors = E[X₁ + X₂ + ... + X₇] = E[X₁] + E[X₂] + ... + E[X₇]

Since all colors are symmetric, E[Xᵢ] is the same for all i:
E[Xᵢ] = P(color i appears at least once) = 1 - P(color i appears zero times)

P(color i appears zero times) = C(60,20)/C(70,20)
Where C(n,k) is the binomial coefficient "n choose k"

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_493 is
   -- Function to calculate binomial coefficient C(n,k)
   function Binomial_Coefficient(n, k : Integer) return Float is
      result : Float := 1.0;
   begin
      if k > n or k < 0 then
         return 0.0;
      end if;
      
      if k = 0 or k = n then
         return 1.0;
      end if;
      
      -- Take advantage of symmetry: C(n,k) = C(n,n-k)
      if k > n - k then
         return Binomial_Coefficient(n, n - k);
      end if;
      
      for i in 1..k loop
         result := result * Float(n - i + 1) / Float(i);
      end loop;
      
      return result;
   end Binomial_Coefficient;

   -- Calculate the probability that a specific color appears at least once
   function Probability_Color_Appears(urn_size, balls_drawn, balls_per_color : Integer) 
      return Float is
      total_combinations : Float;
      zero_combinations : Float;
      prob_zero : Float;
   begin
      total_combinations := Binomial_Coefficient(urn_size, balls_drawn);
      zero_combinations := Binomial_Coefficient(urn_size - balls_per_color, balls_drawn);
      
      if total_combinations = 0.0 then
         return 0.0;
      end if;
      
      prob_zero := zero_combinations / total_combinations;
      return 1.0 - prob_zero;
   end Probability_Color_Appears;

begin
   -- Parameters for the problem:
   -- 70 balls total (10 of each of 7 colors)
   -- Drawing 20 balls
   -- Expected number of distinct colors = 7 * P(color appears at least once)
   
   declare
      total_balls : constant Integer := 70;
      balls_drawn : constant Integer := 20;
      balls_per_color : constant Integer := 10;
      num_colors : constant Integer := 7;
      
      prob_single_color : Float;
      expected_distinct : Float;
   begin
      prob_single_color := Probability_Color_Appears(total_balls, balls_drawn, balls_per_color);
      expected_distinct := Float(num_colors) * prob_single_color;
      
      Put("Expected number of distinct colors: ");
      Put(expected_distinct, Fore => 1, Aft => 9, Exp => 0);
      New_Line;
   end;
   
end Euler_493;
```

## Solution Explanation

The solution uses the linearity of expectation:
1. For each color, we calculate the probability that it appears at least once in our draw
2. This probability equals 1 minus the probability that none of that color's balls are drawn
3. The probability that no balls of a specific color are drawn is C(60,20)/C(70,20) since we're choosing 20 balls from the remaining 60 non-color balls
4. Since all colors are symmetric, we multiply this probability by 7 to get our final answer

## Mathematical Verification

Let's verify with the exact calculation:
- C(70,20) = number of ways to choose 20 balls from 70
- C(60,20) = number of ways to choose 20 balls from 60 (excluding one color)
- P(no balls of a specific color) = C(60,20)/C(70,20)
- P(at least one ball of that color) = 1 - C(60,20)/C(70,20)
- Expected distinct colors = 7 × [1 - C(60,20)/C(70,20)]

The answer should be approximately **6.818741802**.
