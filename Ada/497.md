# Euler Problem 497 Solution in Ada

I'll solve Euler Problem 497, which asks for the expected number of moves to collect all n distinct coupons when each move gives a random coupon.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;
with Ada.Numerics.Elementary_Functions; use Ada.Numerics.Elementary_Functions;

procedure Euler_497 is
   -- Calculate the expected number of moves to collect all n coupons
   -- This follows the coupon collector's problem formula:
   -- E[X] = n * (1 + 1/2 + 1/3 + ... + 1/n) = n * H_n
   -- where H_n is the nth harmonic number
   
   function Harmonic_Number(n : Integer) return Long_Float is
      result : Long_Float := 0.0;
   begin
      for i in 1..n loop
         result := result + 1.0 / Long_Float(i);
      end loop;
      return result;
   end Harmonic_Number;
   
   function Expected_Moves(n : Integer) return Long_Float is
   begin
      return Long_Float(n) * Harmonic_Number(n);
   end Expected_Moves;
   
   -- For large n, we can use the approximation:
   -- H_n ≈ ln(n) + γ + 1/(2n) - 1/(12n²) + 1/(120n⁴)
   -- where γ ≈ 0.5772156649 is Euler's constant
   
   function Approximate_Harmonic(n : Integer) return Long_Float is
      n_L : Long_Float := Long_Float(n);
      gamma : Long_Float := 0.57721566490153286060651209008240243104215933593992;
   begin
      return ln(n_L) + gamma + 1.0/(2.0*n_L) - 1.0/(12.0*n_L**2)
             + 1.0/(120.0*n_L**4);
   end Approximate_Harmonic;
   
   function Approximate_Expected_Moves(n : Integer) return Long_Float is
   begin
      return Long_Float(n) * Approximate_Harmonic(n);
   end Approximate_Expected_Moves;
   
begin
   -- Calculate for n = 1000 (the problem asks for n=1000)
   declare
      n : constant Integer := 1000;
      result : Long_Float;
   begin
      -- Using the exact formula for verification
      result := Expected_Moves(n);
      
      Put_Line("Euler Problem 497 Solution:");
      Put_Line("Expected number of moves to collect all " & 
               Integer'Image(n) & " coupons:");
      Put(result, Fore => 1, Aft => 10, Exp => 0);
      New_Line;
      
      -- Using the approximation for comparison
      result := Approximate_Expected_Moves(n);
      Put_Line("Using approximation:");
      Put(result, Fore => 1, Aft => 10, Exp => 0);
      New_Line;
   end;
   
   -- For the exact answer with sufficient precision:
   -- We can compute this directly for n=1000
   Put_Line("Exact calculation for n=1000:");
   Put_Line("Expected moves = 1000 * H_1000");
   
   -- Show a few terms of the harmonic series to demonstrate
   Put_Line("First 10 terms of H_1000:");
   declare
      h_sum : Long_Float := 0.0;
   begin
      for i in 1..10 loop
         h_sum := h_sum + 1.0 / Long_Float(i);
         Put("H_" & Integer'Image(i) & " = ");
         Put(h_sum, Fore => 1, Aft => 8, Exp => 0);
         New_Line;
      end loop;
   end;
   
end Euler_497;
```

## Mathematical Analysis

Euler Problem 497 is about the **coupon collector's problem**. The expected number of moves to collect all n distinct coupons is:

$$E[X] = n \cdot H_n$$

Where $H_n$ is the nth **harmonic number**:
$$H_n = 1 + \frac{1}{2} + \frac{1}{3} + ... + \frac{1}{n}$$

## Key Insights

1. For large n, the harmonic number can be approximated using:
   $$H_n \approx \ln(n) + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4}$$
   
   Where $\gamma \approx 0.5772156649$ is Euler's constant.

2. For n = 1000, we have:
   $$E[X] \approx 1000 \cdot (\ln(1000) + \gamma + \frac{1}{2000} - \frac{1}{12 \cdot 1000^2} + \frac{1}{120 \cdot 1000^4})$$

3. This gives us approximately 7485.47 moves.

The solution provides both exact computation for smaller values and approximation for large n, demonstrating the mathematical approach to solving this classic probability problem.
