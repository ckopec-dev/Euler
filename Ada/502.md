I'll solve Euler Problem 502, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

## Problem Analysis

The problem requires counting the number of ways to completely cover a 3×n rectangle using 2×1 dominoes (which can be placed horizontally or vertically).

Let's define f(n) as the number of ways to tile a 3×n rectangle.

## Mathematical Approach

For this problem, we need to establish a recurrence relation. Let's consider how we can fill a 3×n rectangle:

- We can place dominoes in various configurations
- The key insight is to think about what happens at the rightmost columns
- This leads to the recurrence: f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)

But let me work more carefully through this:

For a 3×n rectangle, we can think about how to fill the rightmost columns:
1. A vertical domino (2×1) in the last column
2. Two horizontal dominoes (1×2) stacked vertically in the last two columns

After working out the recurrence relation more carefully, the correct recurrence is:

f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)
