# Euler Problem 504 Solution in Ada

I'll solve Euler Problem 504, which asks for the number of lattice points inside a quadrilateral defined by four points.

## Problem Understanding

Euler Problem 504 asks us to find how many lattice points (points with integer coordinates) are contained within a specific type of quadrilateral. The quadrilateral is defined by four points: (0,0), (a,b), (a+b,c), and (c,d) where a, b, c, d are positive integers.

## Solution Approach

I'll use Pick's theorem which relates the area of a polygon to the number of interior and boundary lattice points. For a quadrilateral with vertices at lattice points:
- A = Area of the quadrilateral
- I = Number of interior lattice points  
- B = Number of boundary lattice points
- Formula: I = A - B/2 + 1

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_504 is
   
   -- Function to calculate greatest common divisor
   function GCD(a, b : Integer) return Integer is
   begin
      if b = 0 then
         return a;
      else
         return GCD(b, a mod b);
      end if;
   end GCD;
   
   -- Function to calculate number of boundary points on a line segment
   function Boundary_Points(x1, y1, x2, y2 : Integer) return Integer is
      dx : constant Integer := abs(x2 - x1);
      dy : constant Integer := abs(y2 - y1);
   begin
      return GCD(dx, dy) + 1;
   end Boundary_Points;
   
   -- Function to calculate area of quadrilateral using shoelace formula
   function Area(a, b, c, d : Integer) return Integer is
      -- Quadrilateral with vertices: (0,0), (a,b), (a+b,c), (c,d)
      -- Using shoelace formula for polygon area
   begin
      return abs(a*d - b*c);
   end Area;
   
   -- Function to calculate number of interior lattice points
   function Interior_Count(a, b, c, d : Integer) return Integer is
      area : constant Integer := Area(a, b, c, d);
      boundary : Integer := 0;
      
      -- Calculate boundary points for each edge
      -- Edge 1: (0,0) to (a,b)
      boundary := boundary + Boundary_Points(0, 0, a, b) - 1;
      
      -- Edge 2: (a,b) to (a+b,c)
      boundary := boundary + Boundary_Points(a, b, a+b, c) - 1;
      
      -- Edge 3: (a+b,c) to (c,d)
      boundary := boundary + Boundary_Points(a+b, c, c, d) - 1;
      
      -- Edge 4: (c,d) to (0,0)
      boundary := boundary + Boundary_Points(c, d, 0, 0) - 1;
      
      -- Apply Pick's theorem: I = A - B/2 + 1
   begin
      return area - boundary/2 + 1;
   end Interior_Count;
   
   -- Main calculation
   total : Integer := 0;
   max_a : constant Integer := 100;
begin
   for a in 1..max_a loop
      for b in 1..max_a loop
         for c in 1..max_a loop
            for d in 1..max_a loop
               if Interior_Count(a, b, c, d) > 0 then
                  total := total + 1;
               end if;
            end loop;
         end loop;
      end loop;
   end loop;
   
   Put("Result: ");
   Put(total);
   New_Line;
end Euler_504;
```

## Key Insights

1. **Pick's Theorem**: This is the core mathematical principle that relates area, boundary points, and interior points
2. **Boundary Point Calculation**: Uses GCD to count lattice points on line segments
3. **Shoelace Formula**: For calculating the area of the quadrilateral
4. **Optimization**: The problem asks for a specific range, so we iterate through all combinations

## Mathematical Background

The quadrilateral has vertices:
- (0, 0)
- (a, b)  
- (a+b, c)
- (c, d)

Using Pick's theorem: I = A - B/2 + 1 where:
- A is the area calculated with shoelace formula
- B is the total number of boundary lattice points
- I is the number of interior lattice points

## Complexity Analysis

The solution has O(n⁴) complexity where n=100, which is manageable for this problem. The algorithm:
1. Iterates through all combinations of (a,b,c,d)
2. For each combination, calculates the area and boundary points
3. Applies Pick's theorem to get interior point count
4. Counts valid cases where interior points > 0

This approach efficiently solves Euler Problem 504 by leveraging mathematical properties rather than brute force lattice point counting.
