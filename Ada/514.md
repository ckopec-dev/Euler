## Problem Understanding

Euler Problem 514 asks us to find the number of ways to write n as a sum of positive integers, where each integer is at least 2, and we consider two sums to be the same if one can be obtained from the other by rearranging the terms.

## Mathematical Approach

This is a classic partition function problem with a constraint. The number of partitions of n into parts ≥ 2 can be calculated using dynamic programming or generating functions.

Let's define P(n,k) = number of partitions of n using parts ≥ k.
Then P(n,2) is what we want.

We can use the recurrence relation:
- P(n,k) = P(n,k+1) + P(n-k,k) for n ≥ k
- P(n,k) = 0 for n < k  
- P(n,n) = 1
- P(n,k) = 0 for k > n

Or more directly, we can use:
P(n,2) = P(n,3) + P(n-2,2)

         end loop;
      end loop;

   end Count_Partitions;

The solution uses dynamic programming where:
1. `DP[i]` represents the number of partitions of integer `i` using parts ≥ 2
2. We initialize `DP[0] = 1` (one way to partition 0 - the empty partition)
3. For each part size `i` from 2 to n, we update all possible sums that can include this part
4. The recurrence relation is: `DP[j] = DP[j] + DP[j-i]` for all j ≥ i

This gives us the number of partitions of 1000000 into parts each at least 2.
