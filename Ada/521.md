# Euler Problem 521 Solution in Ada

This problem asks us to find the sum of all integers n ≤ 10^18 such that the sum of digits of n equals the sum of digits of 2n.

Let me analyze the mathematical properties first, then implement in Ada.

## Mathematical Analysis

For a number n with digit sum s(n), we want s(n) = s(2n).

Key insights:
- When multiplying by 2, carries occur that can change digit sums
- The condition is satisfied when there are no carries in the multiplication
- More generally, we need to find numbers where doubling doesn't change the digit sum significantly
