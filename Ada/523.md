# Euler Problem 523 Solution in Ada

I'll solve Euler Problem 523, which asks for the expected number of moves to collect all types of coupons when there are n different types of coupons.

## Problem Analysis

The problem is about finding the expected number of random draws needed to collect all n distinct items (coupons). This is a classic "Coupon Collector's Problem".

Let E(n) be the expected number of draws to collect all n coupons.
- When we have 0 coupons, we need E(n) = n * H_n draws on average, where H_n is the nth harmonic number
- For n = 1, E(1) = 1
- For general n: E(n) = n * (1 + 1/2 + 1/3 + ... + 1/n)

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_523 is
   type Float_Type is new Float;
   
   function Harmonic_Number(n : Integer) return Float_Type is
      sum : Float_Type := 0.0;
   begin
      for i in 1 .. n loop
         sum := sum + 1.0 / Float_Type(i);
      end loop;
      return sum;
   end Harmonic_Number;
   
   function Expected_Moves(n : Integer) return Float_Type is
   begin
      return Float_Type(n) * Harmonic_Number(n);
   end Expected_Moves;
   
   -- Calculate for n = 100 (the problem asks for n=100)
   N : constant Integer := 100;
   Result : Float_Type;
   
begin
   Result := Expected_Moves(N);
   Put("Euler Problem 523 - Expected number of moves to collect ");
   Put(N, Fore => 1, Aft => 0, Exp => 0);
   Put(" coupons: ");
   Put(Result, Fore => 1, Aft => 6, Exp => 0);
   New_Line;
   
   -- For verification with smaller cases
   Put_Line("Verification for small values:");
   for i in 1 .. 5 loop
      Put("E("); Put(i, Fore => 1, Aft => 0, Exp => 0); 
      Put(") = "); Put(Expected_Moves(i), Fore => 1, Aft => 6, Exp => 0);
      New_Line;
   end loop;
end Euler_523;
```

## Mathematical Explanation

The expected number of moves to collect all n coupons follows the formula:

**E(n) = n × H_n**

Where:
- H_n = 1 + 1/2 + 1/3 + ... + 1/n is the nth harmonic number
- This represents the sum of reciprocals from 1 to n

For large n, the harmonic number approaches ln(n) + γ (where γ ≈ 0.5772156649 is Euler's constant), so:
**E(n) ≈ n × (ln(n) + γ)**
