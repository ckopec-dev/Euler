# Euler Problem 527 Solution in Ada

I'll solve Euler Problem 527, which asks for the expected number of coin flips needed to get three consecutive heads.

## Problem Analysis

The problem asks for the expected number of coin flips to get three consecutive heads (HHH). This is a classic Markov chain problem where we need to calculate expected values.

Let me define states:
- State 0: No progress toward HHH
- State 1: One H achieved
- State 2: Two H's achieved (HH)
- State 3: Three H's achieved (HHH) - absorbing state

## Solution Approach

I'll use the method of setting up and solving linear equations for expected values, or implement a Markov chain simulation.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Numerics.Float_Random; use Ada.Numerics.Float_Random;

procedure Euler_527 is
   
   -- Number of consecutive heads needed
   N : constant := 3;
   
   -- Expected number of flips to get N consecutive heads
   function Expected_Flips(N : Positive) return Float is
      -- Using the recurrence relation for expected flips to get n consecutive heads
      -- E(n) = 2 * (E(n-1) + 1)
      -- With base case E(0) = 0
      E : array (0 .. N) of Float := (others => 0.0);
   begin
      for i in 1 .. N loop
         E(i) := 2.0 * (E(i-1) + 1.0);
      end loop;
      return E(N);
   end Expected_Flips;
   
   -- Alternative implementation using the general formula
   function Expected_Flips_General(N : Positive) return Float is
      -- For n consecutive heads, E(n) = 2^(n+1) - 2
   begin
      return (2.0 ** (N + 1)) - 2.0;
   end Expected_Flips_General;
   
   -- Simulation approach for verification
   function Simulate_Expected_Flips(Num_Simulations : Positive := 1000000) return Float is
      type Flip is (Heads, Tails);
      
      function Random_Flip return Flip is
         R : constant Float := Random;
      begin
         if R < 0.5 then
            return Heads;
         else
            return Tails;
         end if;
      end Random_Flip;
      
      Total_Flips : Float := 0.0;
      Current_Heads : Natural := 0;
      Flip_Count : Natural := 0;
      Simulation_Count : Positive := 0;
   begin
      for Sim in 1 .. Num_Simulations loop
         Current_Heads := 0;
         Flip_Count := 0;
         
         loop
            Flip_Count := Flip_Count + 1;
            if Random_Flip = Heads then
               Current_Heads := Current_Heads + 1;
               if Current_Heads = N then
                  exit;
               end if;
            else
               Current_Heads := 0;
            end if;
         end loop;
         
         Total_Flips := Total_Flips + Float(Flip_Count);
         Simulation_Count := Sim;
      end loop;
      
      return Total_Flips / Float(Simulation_Count);
   end Simulate_Expected_Flips;

begin
   -- Calculate using the direct formula
   Put_Line("Expected number of flips to get 3 consecutive heads:");
   Put_Line("Using recurrence relation: " & 
            Float'Image(Expected_Flips(3)));
   
   Put_Line("Using general formula: " & 
            Float'Image(Expected_Flips_General(3)));
   
   -- Show the exact answer
   Put_Line("Exact expected value: 14.0");
   
   -- Verification through simulation (commented out for performance)
   -- Put_Line("Simulation result: " & Float'Image(Simulate_Expected_Flips(1000000)));
   
end Euler_527;
```

## Mathematical Explanation

The expected number of flips to get n consecutive heads follows this pattern:

- E(0) = 0
- E(n) = 2 × (E(n-1) + 1) for n ≥ 1

This recurrence relation can be solved to give the formula:
**E(n) = 2^(n+1) - 2**

For n = 3:
E(3) = 2^4 - 2 = 16 - 2 = **14**

## Verification

The mathematical solution gives us exactly 14.0 flips on average to get three consecutive heads.

The recurrence relation works because:
- From any state, we have a 50% chance of getting the next required head
- If we get it, we advance one step
- If we don't, we reset to the beginning
- The expected value calculation accounts for this probabilistic behavior

Therefore, **the answer to Euler Problem 527 is 14.0**.

The solution uses both mathematical derivation and verification through the recurrence relation approach, confirming that on average, it takes 14 coin flips to achieve three consecutive heads.
