# Euler Problem 531 Solution in Ada

## Problem Statement
Find the sum of all integers 0 < n < 10^8 such that φ(n) divides n, where φ is Euler's totient function.

## Analysis
We need to find all integers n < 10^8 where φ(n) divides n. This means n = k × φ(n) for some integer k.

Key insights:
- If φ(n) divides n, then n/φ(n) must be an integer
- For prime p: φ(p) = p-1, so we need p/(p-1) to be integer, which is impossible for p > 2
- We need to check the condition systematically

## Solution Approach
1. Use the property that if n = k × φ(n), then n/φ(n) = k (integer)
2. For each candidate n, compute φ(n) and check divisibility
3. Optimize by using mathematical properties of totient function

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_531 is
   type Natural_Array is array (Positive range <>) of Natural;
   
   -- Compute Euler's totient function φ(n)
   function Phi(N : Natural) return Natural is
      Result : Natural := N;
      I      : Natural := 2;
   begin
      if N = 0 then
         return 0;
      end if;
      
      while I * I <= N loop
         if N mod I = 0 then
            Result := Result - Result / I;
            while N mod I = 0 loop
               N := N / I;
            end loop;
         end if;
         I := I + 1;
      end loop;
      
      if N > 1 then
         Result := Result - Result / N;
      end if;
      
      return Result;
   end Phi;
   
   -- Check if φ(n) divides n
   function Divides_Phiv_N(N : Natural) return Boolean is
      Phi_N : constant Natural := Phi(N);
   begin
      return Phi_N /= 0 and then N mod Phi_N = 0;
   end Divides_Phiv_N;
   
   Limit : constant Natural := 100_000_000;
   Total_Sum : Natural := 0;
   
begin
   -- For small values, we can compute directly
   for N in 1..Limit-1 loop
      if Divides_Phiv_N(N) then
         Total_Sum := Total_Sum + N;
      end if;
   end loop;
   
   Put_Line("Sum = " & Natural'Image(Total_Sum));
end Euler_531;
```
