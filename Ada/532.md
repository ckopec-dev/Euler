# Euler Problem 532 Solution in Ada

I'll solve Euler Problem 532, which asks for the number of ways to write n as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

We need to find the number of ways to express a number n as a sum of powers of 2 (1, 2, 4, 8, 16, ...) where each power can be used at most twice.

This is equivalent to finding the coefficient of x^n in the expansion of:
(1 + x)(1 + x²)(1 + x⁴)(1 + x⁸)... 

Where each factor (1 + x^(2^k)) represents that we can use 2^k zero times or once, but not twice.

(1 + x + x²)(1 + x² + x⁴)(1 + x⁴ + x⁸)...

   -- Function to count ways to write n as sum of powers of 2
   -- where each power can be used at most twice
   function Ways(n : Long_Long_Integer) return Long_Long_Integer is
      result : Long_Long_Integer := 0;
   begin
      if n = 0 then
         return 1;
      elsif n < 0 then
         return 0;
      elsif Count(n) /= -1 then
         return Count(n);
      else
         -- Try all powers of 2 that are <= n
         declare
            power : Long_Long_Integer := 1;
         begin
            while power <= n loop
               -- Use 0, 1, or 2 copies of this power
               if n >= power then
                  result := result + Ways(n - power);
               end if;
               if n >= 2 * power then
                  result := result + Ways(n - 2 * power);
               end if;
               power := power * 2;
            end loop;
            
            Count(n) := result;
            return result;
         end;
      end if;
   end Ways;

## Mathematical Analysis

The problem can be approached using generating functions. The generating function for this problem is:

$$f(x) = \prod_{k=0}^{\infty} (1 + x^{2^k} + x^{2 \cdot 2^k}) = \prod_{k=0}^{\infty} (1 + x^{2^k} + x^{2^{k+1}})$$

This represents that for each power $2^k$, we can use it 0, 1, or 2 times.
