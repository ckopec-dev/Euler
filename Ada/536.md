# Euler Problem 536 Solution in Ada

Euler Problem 536 asks us to find the number of integers n ≤ 10^18 such that φ(n) = n - 1, where φ is Euler's totient function.

Let me analyze this problem first:
- We want φ(n) = n - 1
- Since φ(n) counts numbers less than n that are coprime to n, we have φ(n) ≤ n - 1
- Equality occurs when all numbers from 1 to n-1 are coprime to n
- This means n is a prime number (since only primes have all numbers less than them coprime to them)

However, let me reconsider. For φ(n) = n - 1, we need n to be such that every number from 1 to n-1 is coprime to n. This happens when n is a prime number.

But wait, let's check the case where n = 1:
- φ(1) = 1
- n - 1 = 0
- So φ(1) ≠ 1 - 1

Let me think more carefully: if n > 1, then φ(n) = n - 1 means all numbers from 1 to n-1 are coprime to n. This is true only when n is prime.

But there's one exception we need to consider - let me verify with small cases:
- For n = 2: φ(2) = 1, and 2-1 = 1 ✓
- For n = 3: φ(3) = 2, and 3-1 = 2 ✓  
- For n = 4: φ(4) = 2, and 4-1 = 3 ✗

So we're looking for primes p such that p - 1 = φ(p). Since φ(p) = p - 1 for prime p, all primes work.

But the question is asking for integers n ≤ 10^18 where φ(n) = n - 1. 

Actually, let me be more precise: we want to find all n such that φ(n) = n - 1.

This condition holds if and only if n is a prime number or n = 1.
- For n = 1: φ(1) = 1, n - 1 = 0. So it doesn't satisfy the equation.
- For prime p: φ(p) = p - 1, so it satisfies the equation.
- For composite n > 1: We have φ(n) < n - 1.

So we're looking for primes ≤ 10^18.
