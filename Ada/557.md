# Euler Problem 557 Solution in Ada

I'll solve Euler Problem 557, which asks for the number of ways to arrange n points on a circle such that no three chords intersect at the same point inside the circle.

## Problem Analysis

Euler Problem 557 asks us to find the number of ways to arrange n points on a circle where:
- No three chords intersect at the same point inside the circle
- We want to count the number of valid arrangements

This is related to Catalan numbers and the problem of counting non-crossing partitions.

procedure Euler_557 is
   
   -- Function to calculate Catalan numbers
   function Catalan(n : Integer) return Long_Long_Integer is
      C : Long_Long_Integer := 1;
   begin
      for i in 1..n loop
         C := C * (4 * i - 2) / (i + 1);
      end loop;
      return C;
   end Catalan;
   
   -- Function to calculate the number of valid arrangements
   function Count_Arrangements(n : Integer) return Long_Long_Integer is
      -- This represents the number of non-crossing partitions
      -- For n points, it's the nth Catalan number
   begin
      if n <= 0 then
         return 0;
      elsif n = 1 then
         return 1;
      else
         return Catalan(n - 1);
      end if;
   end Count_Arrangements;
   
   -- Alternative approach using direct formula for Catalan numbers
   function Catalan_Direct(n : Integer) return Long_Long_Integer is
      Result : Long_Long_Integer := 1;
      i : Integer;
   begin
      for i in 1..n loop
         Result := Result * (2 * (2 * i - 1)) / (i + 1);
      end loop;
      return Result;
   end Catalan_Direct;
   
   -- Function to compute binomial coefficient C(n,k)
   function Binomial(n, k : Integer) return Long_Long_Integer is
      Result : Long_Long_Integer := 1;
      i : Integer;
   begin
      if k > n or k < 0 then
         return 0;
      end if;
      
      if k = 0 or k = n then
         return 1;
      end if;
      
      -- Take advantage of symmetry
      if k > n - k then
         k := n - k;
      end if;
      
      for i in 1..k loop
         Result := Result * (n - i + 1) / i;
      end loop;
      
      return Result;
   end Binomial;

      -- This problem is about counting non-crossing partitions of points on a circle

         return 1;

## Mathematical Background

The solution relates to Catalan numbers because:

1. **Catalan Numbers**: The nth Catalan number counts:
   - Non-crossing partitions of n points on a circle
   - Valid parentheses sequences of length 2n
   - Binary trees with n nodes
   - Non-crossing chords on a circle

2. **Formula**: The nth Catalan number is given by:
   ```
   C(n) = (1/(n+1)) * C(2n, n) = (2n)! / ((n+1)! * n!)
   ```

3. **Recurrence Relation**:
   ```
   C(0) = 1
   C(n) = Σ(i=0 to n-1) C(i) * C(n-1-i)
   ```
